# Tags on guild entries

Type: AFK

## State

Completed

## What to build

Keyword rules assign tags in the groups Focus, Intensity, Wants, Schedule, Language/Region and Other. A guild's tags are the union over all its messages and remember the trigger word. Rows show the tags, and hovering over a tag shows which word set it.

## Acceptance criteria

- [x] Tags.extract covers every tag group, including class plurals and 'all classes' (unit tests)
- [x] A guild's tags combine all its messages
- [x] Rows show tags; the tooltip names the trigger word
