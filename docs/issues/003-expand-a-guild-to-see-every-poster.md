# Expand a guild to see every poster

Type: AFK

## State

Open

## What to build

Clicking a row expands it to show every poster's messages with times and counts. Identical repeats from the same poster are stored once, with a count and a last-seen time. Each poster has a Whisper button.

## Acceptance criteria

- [ ] Identical repeats increase the count instead of adding a message (unit test)
- [ ] The expanded row lists every poster with message, time and count
- [ ] The Whisper button opens a whisper to that poster
