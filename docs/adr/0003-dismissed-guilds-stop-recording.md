# Dismissing a guild stops recording it, account-wide

"Not interested" is stored account-wide (guilds are keyed per realm, and a faction only sees its own chat anyway). The addon keeps only a small dismissed record (name, date, the tags at the time) and stops storing that guild's messages, which keeps SavedVariables small and the list quiet. Dismissed records are never pruned, and they can be restored from a Dismissed tab. Dismissing an "Unknown guild" entry dismisses that **poster**. If the poster later turns out to belong to a named guild, that guild is not dismissed automatically. Its row only shows a hint.
